# Prédiction du churn client télécom

Prédiction du départ des clients d'un opérateur télécom, avec comparaison de 5 modèles de Machine Learning et un dashboard interactif.

## Objectif
Identifier les clients susceptibles de quitter l'opérateur afin d'orienter les actions de fidélisation.

## Étapes du projet
1. Préparation et analyse des données clients avec Python et R
2. Rééquilibrage des classes avec la méthode ROSE
3. Comparaison de 5 modèles de Machine Learning
4. Développement d'un dashboard interactif avec Streamlit pour explorer les résultats et les prédictions

## Technologies
Python · R · Machine Learning · Streamlit
